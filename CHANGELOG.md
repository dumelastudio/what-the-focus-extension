# Changelog

## 0.3.13

- Theme and language follow the device by default. The theme icon cycles through the available modes, and the globe opens the language menu by pointer, touch or keyboard.
- First public source release on GitHub.

## 0.3.12

- Registered Brazilian Portuguese as `pt_BR` in Chrome's localized manifest so it can appear in the Chrome Web Store listing.

## 0.3.11

- Hiding the unread count on the tab icon also removes the unread prefix from the tab title.

## 0.3.10

- Added continuous browser notification silencing and an optional fixed tab icon.

## 0.3.5 through 0.3.9

- Updated detection for Archived and Status shortcuts and restored full-size avatars when status rings are hidden.
- Added the What the Focus home and sidebar shortcut inside WhatsApp Web.

## 0.3.1 through 0.3.4

- Added local active-time totals, timed focus sessions and optional notification silencing.
- Refined appearance and language controls, increased text size, and moved the page counter into the chat-list header.

## 0.3.0

- Added independent distraction switches, localized themes and bundled product and privacy pages.
