# Security and privacy reports

Send suspected vulnerabilities or privacy issues to [Dumela support](mailto:hello@dumela.tv). Use a subject like **What the Focus security report**. Include the extension version, Chrome version and OS, the affected feature, and steps with synthetic data when possible.

Please omit passwords, tokens, QR codes, chat contents and contact details. Use a public issue for ordinary behavior or translation bugs that contain no sensitive data. Coordinate disclosure through the support address if a report needs to be discussed before it goes public.

Use the latest published build for a reproduction when possible. Chrome Web Store review and GitHub releases follow separate schedules, so include the installation source as well as the version.
